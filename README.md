# Vision-Based Landslide Forecasting Using Satellite Imagery

This repository contains the code and data for the Vision-Based Systems Group Assessment.
The objective is to design, implement, and evaluate an experimental Vision-Based Landslide Forecasting System using satellite imagery.

## Dataset
The landslide boundary demarcation dataset (2025 Ditwah Cyclonic Storm) was prepared by the **Arthur C. Clarke Institute for Modern Technologies**, Sri Lanka.
